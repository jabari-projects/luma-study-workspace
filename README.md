LUMA — AI‑Assisted Study Workspace
LUMA is a study platform I’m developing to centralize notes, flashcards, summaries, study sessions, public study‑set discovery, and AI‑powered learning tools. The goal is to make studying feel organized, fast, and intuitive — whether you’re turning images into notes, turning audio into transcripts, or reviewing flashcards generated from your own material.

I designed LUMA around a React + TypeScript + Vite frontend and a FastAPI/Python backend, with Supabase handling authentication and data storage. The platform integrates OpenAI and Deepgram to support tutoring, summarization, and transcription workflows.

While I use Codex to speed up development, the system design, direction of developement, and implementation decisions are all from me — LUMA reflects how I personally approach learning and software engineering.

Features: 
Notes, flashcards, summaries, and study sessions
AI tutor + AI‑generated study materials
Image‑to‑notes conversion
Audio transcription
Public study‑set discovery
Clean, fast UI built with React + Vite
Secure authentication + storage via Supabase
Python/FastAPI backend for processing + routing

Tech Stack:
Frontend: React, TypeScript, Vite
Backend: FastAPI (Python)
Database/Auth: Supabase
AI Integrations: OpenAI, Deepgram
Build Tools: Vite, pnpm
